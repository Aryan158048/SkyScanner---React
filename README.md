# ✈️ SkyScanner React Clone

A sleek, modern flight calendar and booking interface built using **React** and **Backpack** (Skyscanner's design system). This project replicates core features of Skyscanner, offering an intuitive UI for searching and selecting flights across a visual calendar.

🌐 **Live Demo:** [SkyScanner---React](https://aryan158048.github.io/SkyScanner---React)

## 🔧 Tech Stack

- ⚛️ React
- 🎒 Backpack by Skyscanner
- 📦 Vite
- 🖌️ CSS Modules / Backpack styles
- 🚀 GitHub Pages for deployment
  
## 📂 Features

- 📅 Interactive calendar-based flight selection
- 🧭 Simple and responsive navigation bar
- 💼 Modular Backpack UI components
- 🌍 Clean and travel-themed aesthetic inspired by Skyscanner

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Aryan158048/SkyScanner---React.git
cd SkyScanner---React

# Install dependencies
npm install

# Run the development server
npm run dev
